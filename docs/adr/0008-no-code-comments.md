# 0008. Claude는 코드와 설정 파일에 주석을 쓰지 않는다

- 상태: 채택
- 날짜: 2026-11-15

## 맥락

주석은 코드와 따로 낡는다. 지식이 주석으로 흩어지면 사람도 에이전트도 무엇이 최신인지 판단할 수 없다.

## 결정

- Claude는 소스와 설정 파일에 주석과 docstring을 쓰지 않는다.
  - 대상 파일: Python, proto, SQL, YAML, Dockerfile, Makefile, 셸, JS 전부
  - TODO, FIXME, 주석 처리한 코드도 쓰지 않는다.
- 설명이 필요하면 이름을 고치거나 함수로 뽑는다.
- 이유는 다음 위치에 적는다.
  - 변경 단위의 이유: 커밋 메시지
  - 서비스의 설계와 알려진 한계: `services/<서비스>/docs/design.md`
  - 저장소 수준의 결정: ADR
- 대상이 아닌 것:
  - 도구가 생성한 주석: alembic autogenerate, buf 생성 코드 등. 지우지 않고 그대로 둔다.
  - 도구가 읽는 지시문: `# type: ignore[...]`, `# pyright: ignore[...]`, `# noqa: ...`, shebang
  - 사람이 쓴 주석: Claude가 임의로 지우지 않는다.

## 결과

- 지식이 정해진 문서에 모인다.
- 코드만 읽어서는 이유를 알 수 없으므로, 설계 문서를 코드와 함께 갱신해야 한다.
- 다른 도구나 플러그인의 지침이 주석을 요구해도 이 규칙이 우선한다.
