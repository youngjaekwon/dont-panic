# 0009. 필요가 확인되기 전에는 도입하지 않는 것들

- 상태: 채택
- 날짜: 2026-11-15

## 맥락

포트폴리오 저장소는 유행하는 도구를 다 넣고 싶은 유혹이 크다. 하지만 쓰지 않는 구성 요소는 유지 비용만 남긴다.

## 결정

다음은 필요가 확인될 때 별도 ADR로 도입한다.

| 도구 | 도입 조건 |
|---|---|
| GitOps (ArgoCD) | 원격 클러스터에 지속적으로 배포할 때 |
| 서비스 메시 | mTLS나 트래픽 정책을 서비스 코드 밖에서 강제해야 할 때 |
| 스키마 레지스트리 | buf breaking 검사로 이벤트 호환성을 관리하지 못할 때 |
| Skaffold, Tilt | k3d 개발 루프가 병목이 될 때 |
| 서비스 공통 프레임워크 | 세 번째 서비스에서도 같은 코드가 반복될 때 |
| Debezium | outbox relay가 병목이 될 때 |

## 결과

- 새 인프라 구성 요소나 횡단 라이브러리는 ADR을 먼저 쓰고 도입한다.
